# NYC Side Quest

**Phyllis Chen — Introduction to Coding for Learning Designers**

## About my project

NYC Side Quest is an app idea that helps people find something fun to do in New York when they have free time. Users can choose how much time they have, explore activity suggestions, and eventually collect memories from the places they visit.

## How to view it

Open `index.html` in a browser, choose a time, and click **Let's explore**. You can also open `explore.html` directly.

**GitHub repository:** https://github.com/Phyllis111-cxy/f26-nyu-codealong-01-Chen-Phyllis

**My design:** [Assignment 4 Figma](https://www.figma.com/design/MfJCpVKbzRV3SSYDU4AQB2/Phyllis-Chen-%E2%80%94-Assignment-4-%E2%80%94-NYC-Side-Quest)

## What I built

For Assignment 5, I started building the pages with HTML and CSS. I used a warm paper background, yellow highlights, and a simple navigation bar to follow my design.

For Assignment 6, I added JavaScript to the Explore page. I made an array of six NYC activities and used a loop to create the activity cards. Users can filter by time, choose solo or with friends, try **Surprise Me**, and open a card to see more details.

I also updated the first page so users can choose their time before entering Explore. The Calendar now shows a monthly grid with example activities. Collection and Map are still basic pages that I want to build further.

## What was challenging

I had to make sure the different pages linked together and that the JavaScript cards still worked when I changed the layout. I also learned that a page can look fine even when a link or part of the code is not working as expected.
